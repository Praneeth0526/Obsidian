Production NLP Search (Future Plan)

Goal:
Replace the current template/rule-based parsing with a robust NLP model that can
understand user intent, extract structured filters, and map them into OpenSearch
queries. This enables reliable natural language search in production.

Supported File Formats (must be indexed and queryable):
- PDF
- DOCX
- Images
- Text files
- PPTX

NLP Output Schema (example):
{
	intent: "search",
	keywords: ["marketing", "deck"],
	filters: [
		"type:pdf",
		"date:2026-05-07",
		"size_gt:10MB"
	]
}

Mapping Rules (NLP -> OpenSearch):
- type:pdf -> extension: pdf OR content_type: application/pdf
- type:docx -> content_type: application/vnd.openxmlformats-officedocument.wordprocessingml.document
- type:pptx -> content_type: application/vnd.openxmlformats-officedocument.presentationml.presentation
- type:image -> content_type prefix: image/
- type:text -> content_type: text/plain
- date:YYYY-MM-DD -> last_modified range for that day
- size_gt/size_lt -> size_bytes range filter

Implementation Notes:
- Use an LLM or domain-tuned NLP model to extract intent, keywords, and filters.
- Validate filters and fall back to keyword-only search when NLP is uncertain.
- Keep embeddings for semantic matching (future kNN in OpenSearch).
